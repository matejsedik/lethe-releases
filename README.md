# Lethe – anonymizér zmlúv: vydania

Tu sú zverejnené inštalačné súbory programu **Lethe** (anonymizér zmlúv pre Windows).
Zdrojový kód programu tu nie je.

## Stiahnutie

Otvorte záložku **Releases** a pri najnovšom vydaní stiahnite:

- `Anonymizer-Setup-X.Y.Z.exe` – inštalátor s programom Tesseract (funguje aj bez internetu),
- `Anonymizer-Setup-X.Y.Z-online.exe` – menší inštalátor, Tesseract stiahne pri inštalácii, ak v počítači chýba.

Pri každom inštalátore je súbor `.sha256` s jeho odtlačkom (kontrola, že súbor nie je poškodený).

## Aktualizácie

Nainštalovaný program sa (ak to v ňom povolíte) raz denne pozrie sem, či je k dispozícii nová verzia,
a ponúkne jej inštaláciu. Pri kontrole sa neodosiela nič z vašich dokumentov ani nastavení.

Zoznam zmien: `ZMENY.md`.
